Built with the MERN stack (MongoDB, Express, React, Node.js), this platform provides a complete solution for creating, managing, and analyzing quiz assessments with enterprise-grade security features.

## 🛠️ Development

### Prerequisites
- Node.js 18+
- MongoDB 6+
- npm or yarn

### Setup Development Environment

1. **Clone Repository**
```bash
git clone https://github.com/Chetankhaped/Online-Quiz-Questionnaire-Platform.git
cd Online-Quiz-Questionnaire-Platform
```

2. **Install Backend Dependencies**
```bash
cd backend
npm install
```

3. **Install Frontend Dependencies**
```bash
cd frontend
npm install
```

4. **Configure Environment Variables**
```bash
# Backend
cd backend
cp .env.example .env
# Edit .env with your configuration

# Frontend
cd frontend
cp .env.example .env
# Edit .env with your configuration
```

5. **Start MongoDB**
```bash
# Using Docker
docker run -d -p 27017:27017 --name mongodb mongo:6

# Or start local MongoDB
mongod
```

6. **Seed Demo Data**
```bash
cd backend
node src/utils/seedData.js
```

7. **Start Development Servers**
```bash
# Terminal 1: Backend
cd backend
npm run dev

# Terminal 2: Frontend
cd frontend
npm run dev
```

### Development Commands

#### Backend
```bash
npm run dev          # Start with nodemon
npm start            # Start production
npm test             # Run tests
npm run lint         # Lint code
```

#### Frontend
```bash
npm run dev          # Start dev server
npm run build        # Production build
npm run preview      # Preview build
npm test             # Run tests
npm run lint         # Lint code
```
