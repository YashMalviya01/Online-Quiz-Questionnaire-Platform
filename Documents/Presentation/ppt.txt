Slide 2 — IDEA TITLE (Proposed Solution)

One-liner (positioning):
- A trustworthy, explainable, and scalable deepfake analysis platform for videos and images, designed for public portals, media verification teams, and citizen reporting.

Problem framing:
- Rising quality and availability of synthetic media (face swaps, lip-sync, generative models) undermine public trust and safety.
- Existing detectors struggle with out-of-distribution fakes, poor audio/video sync, and lack of actionable explanations.

Our proposed solution (research plan):
- Multimodal detection combining vision and audio: transformer-based video encoder + MFCC/mel audio features for robust cross-modal cues.
- Explainability by design: Grad-CAM overlays on key frames, A/V sync metric, Laplacian blur heatmaps for fast triage on images and silent videos.
- Operational platform: Web UI for uploads and history, token-based auth, pay-per-analysis via credits, S3-only artifact storage for privacy and scale.

Uniqueness/innovation:
- Dual-path inference: fast heuristic pass (Laplacian sharpness) + heavy model pass (AV transformer) with visual explanations.
- Path-prefix deployment behind ALB/API Gateway and configurable BASE_PATH to handle large uploads in production.
- End-to-end explainable artifacts per session (waveform, mel spectrogram, attention maps, Grad-CAMs, lip landmarks) to aid decisions.

Slide 3 — Technical Approach

Methodology overview (bullets):
- Data: Use public datasets (FaceForensics++, DFDC); augment with compression, scaling, codecs; focus on audio-visual sync perturbations.
- Modeling: Start with a Pinpoint/transformer-style AV fusion (ViT/TimeSformer/ViViT inspirations) over uniformly sampled frames + MFCC/mel.
- Features: Per-frame attention, lip openness series (MediaPipe Face Mesh), audio RMS series aligned on a common time grid.
- Inference flow: Upload → stream-to-disk → frame/audio extraction → heuristic (Laplacian) → model inference (if audio present) → explanations → result JSON.
- Explainability: Grad-CAM heatmaps on selected frames; A/V sync correlation; Laplacian color maps for blur/edge evidence.
- System: FastAPI backend, Nginx static site, Docker Compose for local; S3 for artifact storage; Cognito optional for JWT auth; Credits microservice for pay-per-use.

Suggested flowchart (describe/draw in your slide tool):

  → Upload API (multipart)

  → Branch B (AV Model: frames+MFCC/mel → Transformer) → Score + Grad-CAMs + sync metric
  → Persist artifacts (S3) → Return result JSON → UI renders visuals

Slide 4 — Feasibility and Viability

Feasibility:
- Proven components: FFmpeg/OpenCV extraction, Grad-CAM, MediaPipe lip landmarks, S3 persistence.
- Computation: CPU baseline feasible for Laplacian + frame sampling; GPU optional for faster transformer inference.
- Security: JWT (Cognito) for auth; presigned S3 URLs for artifact access; CORS configured.

Risks/challenges:
- Generalization to unseen fake generation methods (distribution shift).
- Large file uploads via API Gateway; timeouts and 405s.
- Privacy/governance for user-submitted sensitive media.

Mitigations:
- Train with diverse datasets and heavy augmentations; periodic re-training with new fake families.
- Route heavy uploads via ALB path (/engine) and strip prefix in backend; tune chunk size and limits.
- S3-only persistence; data retention policies; encryption at rest; strict CORS and token claims mapping.

Operational viability:
- Credits model to control cost; auto-register with welcome credits; ad-reward hooks.
- Modular microservices (Engine, Website, Credits) for independent scaling.
